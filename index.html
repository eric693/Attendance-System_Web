LINE 打卡的設定會很麻煩嗎？

系統在初始時會協助建好基本設定，並提供教學影片。不過因各公司規則不同，部分細節仍需自行調整。若在操作上有任何疑問，歡迎與我們客服聯繫，我們有專人協助，讓您快速上手、無需煩惱！

適合我們公司使用嗎？

當然，出勤管家適合所有規模的公司。無論你是 5-10 人的小微企業，或是 500 人以上的中大型企業，只要你想用系統降低人事作業時間，並且讓員工在 LINE 上完成一切，出勤管家都是你的最佳選擇。

買斷制和月付訂閱有什麼不同？

買斷制：一次付清、永久使用，長期使用最划算，並享 7 天退款保證。
月付訂閱：按月付費，前期負擔低，可隨時升級方案或取消，取消後下個月起停止計費。

兩種付費方式的功能完全相同。預計使用一年以上，建議選擇買斷制。

有使用人數限制嗎？

不限人數。我們推出的最新限量方案：手機打卡、LINE 打卡不限使用人數，並且是買斷制的付費方式，非常優惠先搶先贏。（BC方案適用 50 人以下，如 50 人以上，歡迎與我們聯繫）

購買之後，該怎麼開始使用？

請於線上選擇要購買的方案，並且完成付款。我們將於 1-2 工作天內與您聯繫，並且協助你設定好公司規則、讓員工直接開始使用。流程說明：完成購買 → 專人設定規則/系統教學 → 開通帳號 → 員工開始使用。

有什麼打卡方式可以選擇？

打卡方式有 GPS 定位打卡、QR Code 打卡、LINE Bot 打卡。GPS 定位打卡需員工抵達指定地點範圍內才可以打卡；QR Code 打卡由管理員產生一次性 QR Code，員工現場掃碼；LINE Bot 打卡可直接在 LINE 對話中完成。

怎麼防止員工還沒到公司就打卡？

你可以設定打卡地點的座標與半徑，員工必須在範圍內才可以進行 GPS 打卡；也可以改用現場掃描一次性 QR Code 的方式打卡。

怎麼防止員工代打卡？

每位員工用自己的 LINE 帳號登入打卡，可再搭配手機的指紋／臉部辨識確認本人。GPS 打卡會檢查是否在公司範圍內；QR Code 由系統簽章且幾分鐘就失效，拍照傳給別人也無法使用。

是否適用輪班、兩頭班的情況？

適用！遲到、早退依照每位員工當天的排班判斷，不同班別各自計算。餐飲、零售常見的兩頭班（例如中午與晚上各上一段），一天最多可以打三組上下班卡，各段工時自動相加；只打一段卡也不會被多扣休息時間。

沒有 LINE 的員工也能使用嗎？

可以！管理員可以為員工產生一次性的登入連結或 QR Code（預設 72 小時內有效），員工用手機開啟後即可登入、打卡。另外也可以在公司放一台平板當打卡站，員工到場掃碼打卡。

如何使用工作日誌功能？

工作日誌功能非常簡單：

員工端：
1. 登入系統後進入「工作日誌」分頁
2. 選擇日期並填寫工作時數
3. 詳細記錄當日工作內容（至少 10 個字）
4. 提交後等待主管審核

主管端：
1. 在管理員介面查看待審核日誌
2. 檢視員工的工作內容與時數
3. 可選擇核准或拒絕，並填寫審核意見
4. 系統會自動通知員工審核結果

提示：被拒絕的日誌可以修改後重新提交

員工要怎麼申請預支或報銷？

在「費用申請」分頁選擇類型後填寫即可：

預支：先向公司借款，核准後會在當月薪資自動扣回（管理員可調整）
報銷：自己先墊付，再憑發票或收據請款

填寫內容：
• 日期、金額、事由
• 發票號碼（選填）
• 發票或收據照片（選填，也可以送出後再補傳）

送出後由管理員核准或駁回，員工可隨時查看每筆申請的狀態與審核意見。

我要怎麼查詢員工遲到幾分鐘？

在出勤報表中，已經自動幫你計算員工每天遲到幾分鐘，可以輕鬆加總遲到分鐘數。再也不用手動計算了！

可以看到員工每日實際上班的工時嗎？

可自動判斷遲到、早退的時間嗎？

可以匯出工作日誌報表嗎？

個人報表：

管理員報表：

管理員可以查到誰做了哪些操作嗎？

每筆紀錄包含操作者、時間與內容，可依月份、操作類型、關鍵字查詢；身分證字號、銀行帳號會自動遮蔽。薪資單另有異動記錄，每次修改都記下哪一欄、從多少改成多少、誰改的。

可以彈性設定不同班別的上下班時間嗎？

我們公司不是休六日，可以自行設定休息日為非六日嗎？

如何批量上傳排班？

步驟4：上傳 CSV 或 Excel 檔案

檔案要求：

• 必填：員工ID、姓名、日期、班別、上下班時間
• 選填：地點、備註
• 日期格式：YYYY-MM-DD
• 時間格式：HH:MM（24小時制）

系統支援哪些薪資類型？

系統支援兩種薪資類型：

月薪制：
• 固定月薪 + 各項津貼/扣款
• 包含：職務加給、伙食費、交通補助、全勤獎金、業績獎金
• 加班費另外計算

時薪制：
• 時薪 × 實際工作時數
• 總工作時數從打卡記錄自動計算
• 加班費依類型不同倍率計算

兩種類型都支援完整的勞健保、勞退自提、所得稅等扣款項目。

加班費如何計算？

系統依勞基法規定自動計算四種加班費：

1. 平日加班（週一～五）
• 前2小時：×1.34
• 第3小時起：×1.67

2. 休息日加班（週六）
• 前2小時：×1.34
• 3-8小時：×1.67
• 第9小時起：×2.67

3. 例假日加班（週日）
• 全部時數：×2.0

4. 國定假日出勤
• 正常工時：×1.0（額外給付）
• 加班時數：×2.0

系統會自動判斷加班類型並計算正確倍率。

國定假日出勤薪資如何計算？

國定假日出勤分為兩部分計算：

出勤薪資：
當日正常工時 × 時薪 × 1.0（額外給付，不扣原薪）

加班費：
超時部分 × 時薪 × 2.0

範例：
月薪36,000（時薪150），國定假日工作10小時
• 出勤薪資：8h × 150 × 1.0 = 1,200元
• 加班費：2h × 150 × 2.0 = 600元
• 合計：1,800元

請假如何扣薪？

系統會自動計算請假扣薪：

病假：扣半薪（時數 × 時薪 × 0.5）
事假：扣全薪（時數 × 時薪 × 1.0）
特休/年假：不扣薪
早退：依早退時數按比例扣款

系統會在薪資明細中分別顯示病假、事假的時數與扣款金額，讓計算更透明。

員工如何查看自己的薪資？

顯示內容包括：

• 詳細的應發項目明細
• 詳細的扣款項目明細
• 工作時數統計（時薪制）
• 加班統計（如有加班）

所有資料都是即時更新，讓員工隨時掌握自己的薪資狀況。

管理員如何計算員工薪資？

管理員操作流程非常簡單：
